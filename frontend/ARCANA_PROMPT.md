# Arcana

The file reference-ui.png is the design reference.

The website must match this design as closely as possible.

Landing page:

- Use dserve.co navbar style
- Arcana logo on left
- Login and Signup buttons on right

Pages required:

- Landing Page
- Login
- Signup
- Dashboard
- Personal Library
- Shared Library
- Create Library
- Manhwa Detail Page
- Profile Page

Requirements:

- React
- Vite
- TypeScript
- Tailwind CSS
- React Router
- Framer Motion

Must support:

- Light Mode
- Dark Mode

Do not redesign.

Follow reference-ui.png exactly.
